# Printing, Ranges, and Loops

In Python, we often need to display information to the user or repeat actions multiple times. This lesson covers how to use the `print()` function for output, the `range()` function for creating sequences of numbers, and `for` loops for iteration.

## The `print()` function

We've seen the `print()` function briefly in earlier lessons. It's a built-in function that displays values to the console. You can print strings, numbers, variables, and even the results of expressions.

```repl
>>> print("Hello, Python learners!")
```

```repl
>>> course_name = "Python Now"
>>> print(course_name)
```

You can print multiple items by separating them with commas. `print()` will automatically add a space between them.

```repl
>>> print("Lesson", 3, "is about loops.")
```

By default, `print()` adds a newline character at the end of the output. You can change this behavior using the `end` argument.

```repl
>>> print("This will be on one line.", end=" ")
>>> print("See?")
```

## The `range()` function

The `range()` function is used to generate a sequence of numbers. It's particularly useful when you want to perform an action a specific number of times in a loop.

`range()` can be called in a few ways:

*   `range(stop)`: Generates numbers from `0` up to (but not including) `stop`.
    ```repl
    >>> list(range(5)) # We use list() here to see the numbers generated by range
    ```
*   `range(start, stop)`: Generates numbers from `start` up to (but not including) `stop`.
    ```repl
    >>> list(range(2, 7))
    ```
*   `range(start, stop, step)`: Generates numbers from `start` up to (but not including) `stop`, incrementing by `step`.
    ```repl
    >>> list(range(0, 10, 2))
    ```

```repl
>>> # Create your ranges here. For example:
my_range = range(1) # Try changing this!
>>> list(my_range) # See the result
```

## `for` Loops

A `for` loop is used to iterate over a sequence (like a list, a string, or the sequence produced by `range()`). This means it will execute a block of code repeatedly for each item in the sequence.

Here's the basic syntax:

```python
# sequence can be a list, string, range, etc.
# item will take the value of each element in the sequence during each iteration

# for item in sequence:
#     # code to execute for each item
#     print(item)
```

Let's see it in action with `range()`:

```python
# Print numbers from 0 to 4
for i in range(5):
    print(i)
```

You can loop over the characters in a string:

```python
for char in "hello":
    print(char)
```

Or loop over items in a list:

```python
colors = ["red", "green", "blue"]
for color in colors:
    print("I like", color)
```

### Example: Summing numbers

Let's use a `for` loop to sum the numbers from 1 to 100.

```python
total = 0
for number in range(1, 101): # range(1, 101) gives numbers from 1 to 100
    total = total + number
print("The sum is:", total)
```
